### OpenAI：迁到 GPT-6.2 的四个硬变化

6.2 换代不只是换模型名。官方《Using GPT-6.2》迁移指南里有四条会让人不知不觉变贵、变差的改动：

1. **改历史会丢推理**。从 GPT-6.2 起，Responses API 在「前缀编辑」（改动本轮之前较早的 developer 消息或 tool call）、跨模型切换（含降级到更便宜的档）、以及终端用户或组织变更之后，会**丢弃之前的 reasoning items**。模型拿不回推理过程，答案质量会下滑，还会重复前面的工作多烧 token。凡是把「裁掉旧 tool 输出」「每步换一套 system prompt」「中途换模型省钱」写进流水线的 agent 循环都会踩这条——**保持前缀不变**既保住推理，也保住 prompt 缓存命中。
2. **顶层 `instructions` 排到了 input 之后**。6.2 起它按追加内容处理，想让它进缓存，得把可复用的指令写成 input 里的**第一条 developer message**；顶层 `instructions` 只留给「仅对本请求生效」的临时指导。
3. **采样参数被取消**。迁到 6.2 要删掉 `temperature`、`top_p`、`logprobs`、`top_logprobs`；Responses 侧还要把 `message.output_text.logprobs` 从 `include` 里去掉。按温度微调风格的旧实验，在 6.2 上只能靠提示词做。
4. **effort 有推荐起点**。新接入从 `medium` 起；原来跑 `none` 或 `minimal` 的，改用 `low`。

另外，Astra 与 Sol 对通过审核的组织支持**零数据留存（ZDR）**：开启后 Responses 把 `store` 当作 `false`，多轮对话要按序回传包含加密 reasoning 的 output items。

### DeepSeek：一个 Key 下的 API 全家桶

DeepSeek 是国内少数把「模型 + 协议 + 周边工具」都收在同一个平台上的厂商。2026 年它的形态分三层：**两个模型名、三种协议格式（外加一个 Beta 通道）、一组不计 token 的周边 API**。

#### 模型层：只有两个名字

| API 模型名 | 对应版本 | 结构 | 上下文 / 输出 | 视觉 | 并发上限 | 低峰价（命中 / 未命中 / 输出，$ per 1M） |
| --- | --- | --- | --- | --- | --- | --- |
| **`deepseek-flash`** | DeepSeek-V4.1-Flash-1017 | 552B MoE，预填充 8B / 解码 16B 激活 | 1M / 384K | ✅ | 2,500 | $0.003 / $0.15 / $0.60 |
| **`deepseek-v4-pro`** | DeepSeek-V4-Pro-0813 | 1.6T MoE / 49B 激活 | 1M / 384K | ❌ | 500 | $0.022 / $0.66 / $1.98 |

**高峰价 = 低峰价 × 2。** 但别被「高峰」吓住：官方定义的高峰只有 **UTC 01:00–04:00 与 06:00–10:00、周一至周五、不含中国法定节假日**——换成北京时间正好是 **09:00–12:00 和 14:00–18:00 两个工作时段**。也就是说**夜里、清晨和整个周末都是半价**，批处理与评测任务挪到晚上能直接砍一半成本。缓存命中约为未命中的 1/50（Flash）和 1/30（Pro），把长 system prompt 和文档固定在请求最前面即可命中。

#### 接口层：三种协议，加一个 Beta 通道

| 格式 | Base URL | 用途 |
| --- | --- | --- |
| OpenAI Chat Completions | `https://api.deepseek.com` | 事实上的默认入口，改个 `base_url` 就能把现有 OpenAI SDK / 工具切过来 |
| OpenAI Responses | 同上 | 新版 agent 接口，Codex 一类工具走这条 |
| Anthropic Messages | `https://api.deepseek.com/anthropic` | 给 Claude Code 及兼容 Anthropic 的客户端直连（走 `x-api-key` 认证） |
| Beta | `https://api.deepseek.com/beta` | FIM 补全、对话前缀续写、严格工具模式 |

两档模型的能力基本对齐：JSON 输出、工具调用、Responses API、Anthropic API、对话前缀续写（Beta）、FIM 补全（Beta，**仅非思考模式**）。硬差异有**两条，都落在 Flash 一侧**：① 图像输入只有 Flash 支持，Pro 是纯文本模型——要「看图改代码」就得走 Flash；② 2026-11-13 开放的内置应用工具（联网、读链接、文件输入、安全检查）也只挂在 `deepseek-flash` 上，`deepseek-v4-pro` 至今不支持。**见到「两档基本对齐」的说法要留个心眼**：凡是涉及多模态与 App 级工具的用法，实际只有 Flash 一条路。

#### 思考模式是开关，不是另一个模型

`deepseek-chat` / `deepseek-reasoner` 两个旧名字已于 **2026-07-24 退役**，R1 式的显式推理变成 V4 的**思考模式**：请求里传 `thinking: {"type": "enabled"}`（**默认就是开启**），`reasoning_effort` 取 `low` / `high`（默认）/ `max`。三个容易踩的点：

- 思考模式下 **`temperature` 无效**，`tool_choice: "required"` 会直接返回 400——这类请求要先把思考关掉
- 默认 `max_tokens` 随档位变：关闭思考 8K、开启 64K、`max` 档 128K
- 带工具的循环里，上一轮的 `reasoning_content` 必须**原样回传**，否则 400；不用工具时可以省略

几个计费与配额细节：搜索/抓取**只对成功请求计费**，失败、空结果、超时都不算钱；两者 QPS 上限分别是 100 与 25，**按账号统计而非按 Key**，和模型并发上限互不占用。**从 2026-11-18 12:00（北京时间）起，模型在对话中自行触发的服务端搜索与抓取不再单独计费**——只按 token 结算；要收费的只剩开发者显式调用 `/v1/tools/*` 那种「搜索 API 本身」。此外还有 `GET /models`、`GET /user/balance` 与 Files 等管理接口。

#### 内置应用能力：把 App 的对话体验做成参数（2026-11-13）

上面那组周边 API 要自己拼装——搜索完把结果回填进上下文、文件解析完再拼 prompt。2026-11-13 官方又开了一条更省事的路子：**在原有 Messages / Responses / Chat Completions 请求里打开对应参数，工具调用与上下文拼接全由服务端完成**，不必自己在客户端写编排。四项能力：

- **联网搜索**（`deepseek_web_search`）：关闭思考时按需搜网页或图片并给出引用；**开启思考时同一个工具会多轮推理式地搜和读链接**
- **文件输入**：上传 PDF、Office 文档、图片，经纯文本抽取或富版面解析后进入对话上下文
- **读链接**（`deepseek_read_url`）：模型自行识别用户消息里的链接并抓取正文
- **安全检查**：审查输入与输出，命中风险时返回拒答标记。**面向公众提供服务必须开启**，并履行内容安全审核、大模型备案、AI 标识等义务

⚠️ **这三件事都只对 `deepseek-flash` 生效，`deepseek-v4-pro` 不支持**——这也是上节说的第二条硬差异。另外官方把整套能力做成了一个开源 Demo 客户端（`chat-demo`），能导入 DeepSeek 的历史对话，可以直接当参考实现看。计费上**只剩 token 一条线**：2026-11-18 12:00（北京）起，这套内置能力触发的搜索与抓取已不再按次收费，「开参数 = 多花钱」的顾虑可以去掉；但显式调 `/v1/tools/search`、`/v1/tools/fetch` 的老路子仍按 $0.75/千次计。

#### 三个名字上的坑

- ⚠️ **`deepseek-v4-flash`、`deepseek-v4-flash-vision-exp` 仍可用，但对应模型已退役**——请求会被路由到 V4.1-Flash 并按 Flash 价计费（2026-09-10 起）。老代码不改也不会报错，但你以为在调旧模型，其实已经换人了。
- ⚠️ **不存在「DeepSeek V4.1-Pro」**。09-10 的发布说明里曾写要把 `deepseek-v4-pro` 的请求临时路由到 Flash「直到 V4.1-Pro 发布」，开发者反对后官方撤回，这个名字至今**没有模型卡、没有价格行、没有权重**。中文文章里给它编的参数与价格，都是把家族数据挪了个标签。
- ⚠️ 官方文档在 `api-docs.deepseek.com`，控制台在 `platform.deepseek.com`；`deepseek.ai` 一类站点是第三方整理页，数字大体对得上但**不能当官方口径引用**。

## 怎么读 2026 年的版本号

2026 下半年起，厂商集体放弃了「一个模型一个版本号」的线性叙事，改成**同代多档 + 推理档位**。直接后果是：**版本号大不等于能力强**。读规格表时先分清四层：

| 层级 | 例子 | 怎么看 |
|------|------|--------|
| **代际** | GPT-6 → GPT-6.1 → GPT-6.2、Gemini 3.8 → Gemini 4 | 只代表训练批次，常伴随架构与知识截止变化 |
| **同代档位** | Astra / Sol / Terra / Luna；Neon / Carbon / Argon / Hydrogen；Opus / Sonnet / Haiku；Luna 型低价档 | **这是同一代的不同裁剪**，Terra 弱于 Sol 不代表「版本更低」 |
| **推理强度** | `low / medium / high / xhigh`、Gemini 的 thinking level、Kimi 的 Highspeed | 同一模型换个档位，分数与成本可以差一倍以上 |
| **渠道与别名** | Bedrock / Vertex / 第三方路由的 ID；`-preview`、`-flash`、`-lite` | 同名不同渠道的限制与价格可能不同，`preview` 还有下线日 |

四条实用规则：

1. **比价前先对齐档位**。「$1/$5」通常是该代最便宜的那一档，拿它和别家的旗舰价比是错的。
2. **`preview` 不是产品**。它随时可能被正式版顶掉、或按日下线——Qwen4-Max 预览 11-11 上线、**11-16 就出了正式版并给出书面价格**，预售期写的调用代码要留好换模型名的余地。判断一个 `preview` 是否值得接，看它有没有**价格页**与**明确下线日**，两者都没有就只当试用。
3. **看到「同代多档」先问一句：它替代的是谁**。厂商常把新档插在旧旗舰下方（如 6.1 Terra 之于 6.1 Sol），不是简单升级；也有反着来的——**6.2 是往顶上盖了一层**（Astra → 6.2 Astra、Sol → 6.1 Sol），旧旗舰没下架但不再是首选，这类「同名换代」最容易按旧价做预算。
4. **模型名可能是个滚动别名**。`deepseek-flash` 恒定指向「该档当前版本」（现在是 V4.1-Flash-1017），厂商升级时你不改一行代码就换了模型。要锁定行为，就把具体版本号写进配置和回归测试，别只记别名。

## 延伸：三种不是「LLM」的模型形态

上面两张表列的都是**可调用的 LLM API**。但 2026 年「模型」这个词的外延已经扩大——选型时会遇到三类形态完全不同的东西，它们的评价标准（benchmark、延迟、成本）与 LLM 不通用。

| 形态 | 代表 | 它做什么 | 关键区别 |
|------|------|---------|---------|
| **决策模型** | Jev（TypeSafe AI）、Gemini Decision 1（Google） | 只输出带概率的类型化判定：分类、评分、真/假 | 不生成文本，结构上无法「胡说」；Jev 延迟 70–500ms（2026-09），Gemini Decision 1 端到端 150–250ms（2026-11-11） |
| **世界模型** | Genie 4、NVIDIA Cosmos、Marble、V-JEPA 2 | 理解并预测物理世界的演化，生成可交互环境 | 吃视频级算力；主战场是仿真与具身智能，尚不能直接替换 LLM |
| **专家混合（MoE）** | 多数前沿开源模型 | 稀疏激活——推理时只调用部分「专家」子网络 | 是**架构**而非产品，决定推理成本与吞吐 |

### 决策模型：Jev

由 TypeSafe AI 于 2026-09 发布，创始人是前 OpenAI 研究员 Diogo Almeida（曾参与 ChatGPT 的指令遵循训练）。它属于「System One」路线：**不生成任何文本**，而是接收结构化状态（工单、消息、JSON），返回带校准置信度的答案。三种提问原语：

- **Choice** —— 从至多 255 个预设选项中选一个，附各选项概率
- **Score** —— 按 2–10 级的有序标准打分，结果可落在两级之间
- **Noul** —— 是/否判断，返回 0–1 的概率（名字取自 Bernoulli）

它的定位是「快慢分工」里的快判断层：昂贵的大模型负责规划（慢思考），高频、原子化的判断交给决策模型。价格约 $0.042 / 百万输入 token，输出不计费。

> ⚠️ **两个使用前提**：① 官方与集成方（Pydantic）均提示 **prompt injection 可影响其判定**——不适合单独作为 agent 的安全门禁；② 计数、算术、日期处理不可靠，且英文优先，**目前未向中国大陆开放**。

### 决策模型的第二个玩家：Gemini Decision 1

2026-11-11 Google 发布了 **Gemini Decisions API** 与驱动它的新模型 **`gemini-decision-1`**，官方博文标题是《Introducing the Gemini Decisions API: Fast, calibrated multimodal decisions》。它和 Jev 是同一类东西（**一次前向算完、只吐概率不吐字**），但工程取舍几乎相反：

| 维度 | Jev（TypeSafe AI） | Gemini Decision 1（Google） |
| --- | --- | --- |
| 输入 | 结构化状态（工单、消息、JSON） | **原生多模态**：文本、图像、音频、视频、PDF 混在同一份输入 |
| 单次规模 | 一次一问 | 一次请求最多 **1,000 个独立问题**，共享输入只计一次费；上下文上限 **256K** |
| 提问原语 | Choice / Score / Noul | 同名三件套：`noul`（是/否）、`choice`（2–255 选项）、`score`（有序量表） |
| 延迟 | 70–500ms | 端到端 **150–250ms**，模型计算中位 50–100ms；1 题加到 100 题延迟几乎不变 |
| 价格 | 约 $0.042 / 百万输入，输出不计费 | **$0.10 / 百万输入，输出不计费**，另不收思考 token、音频转写与 OCR 费 |
| 状态 | 商用 | **Preview**，走 Gemini API `v1beta` 与 AI Studio，有免费层 |

对选型的影响有两条。一是**这一品类不再只有创业公司**：Google 自己已经把它用在 Gemini Notebook 的模型路由（普通查询延迟降约 40%）、Stitch 的流程线框图、Google Labs 的表情选择，以及 Google 搜索里作为 **MCP 工具的安全层**识别对抗行为——也就是说「决策模型负责快判断、生成模型负责慢思考」这套分工，已经从设想变成大厂内部的生产用法。二是**它的短板是校准而非速度**：官方称其在 9 项基准中拿下 7 项第一、校准误差全场最低，但有开发者用免费额度做了 54 次调用后指出：**若候选里没有「其他」兜底，越界输入会被强行塞进已有类别**（置信度还能给到 0.7 以上），而一旦补上「其他」选项，越界样本就都正确落到「其他」。所以对接这类 API 时，**兜底选项与置信度阈值是设计的一部分，不是可选项**。

> ⚠️ 两点边界：① 它**不生成开放式文本**，摘要、创作、多步推理仍要回到生成式模型；② Preview 阶段，接口与定价都可能变，别把它写进长期成本模型。另有同名但不同物——OpenAI 在 10-22 已 GA 的 Decisions API 是闭集打分接口，选型时别把两家的调用形态搞混。

### 世界模型（World Model）

目标是让模型理解物理世界如何演化，而不只是处理语言。2026 年分成两条技术路线：

- **生成式路线** —— 直接生成像素。Google DeepMind **Genie 4**（2026-10 发布，先经 Project Genie 向合格的 Google AI Ultra 订阅者开放；**2026-11-19 起 `genie-4` 在 Gemini API 的 Interactions API（`v1beta`）转为 GA**，只开付费档，**$1.50 / 百万输入、$9.00 / 百万文本输出、$17.50 / 百万视频输出**，约合 **$0.10/秒**且已含立体声，**无免费档**；输出是 **24 fps、16:9 的可操纵视频 + 48 kHz 立体声**，经 WebRTC / WebSockets 流式下发，场景用一句文本、一张 16:9 参考图或两者起，之后用 WASD / 方向键加中途文本事件实时改机位与事件）官方称是其「最真实、最可交互」的一代：不再是单一生成模型，而是**建立在 Gemini 家族之上**——Gemini Omni 负责真实世界的外观与行为，其他 Gemini 模型提供维持模拟连贯性所需的推理；给一句文本或一张图起场景，之后可边跑边用提示词改事件、机位与声音。上一代 **Genie 3**（11B 参数自回归 Transformer，720p / 24fps）是 2026-01 起首批向 AI Ultra 开放的那一版；Waymo 已用这一系列微调出 **Waymo World Model**，专门生成现实中罕见的驾驶场景。NVIDIA **Cosmos** 是开源的世界基础模型平台，主要产出合成训练数据。
- **隐空间路线** —— 只预测表征、不重建像素。Meta **V-JEPA 2** 用约 100 万小时视频预训练，再加仅 62 小时机器人数据，即可零样本完成抓放操作。Yann LeCun 于 2026 年初离开 Meta 创办 **AMI Labs**，专攻这条 JEPA 路线。

目前主要用于自动驾驶仿真、机器人训练与内容生成，**还不是能直接替换 LLM API 的产品**。

### 专家混合（MoE）

MoE 是架构而非产品：模型内部有多个「专家」子网络，每次推理只激活其中一小部分。因此**总参数量**（决定能力上限）与**激活参数量**（决定推理成本）是两个不同的数——看到「总参数 235B / 激活 22B」这类标注就是这种情况。它是当前主流开源模型压低推理成本的通用手段，选型时应关注**激活参数**而非总参数。
