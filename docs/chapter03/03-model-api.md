### DeepSeek：一个 Key 下的 API 全家桶

DeepSeek 是国内少数把「模型 + 协议 + 周边工具」都收在同一个平台上的厂商。2026 年它的形态分三层：**两个模型名、三种协议格式（外加一个 Beta 通道）、一组不计 token 的周边 API**。

#### 模型层：只有两个名字

| API 模型名 | 对应版本 | 结构 | 上下文 / 输出 | 视觉 | 并发上限 | 低峰价（命中 / 未命中 / 输出，$ per 1M） |
| --- | --- | --- | --- | --- | --- | --- |
| **`deepseek-flash`** | DeepSeek-V4.1-Flash-1017 | 552B MoE，预填充 8B / 解码 16B 激活 | 1M / 384K | ✅ | 2,500 | $0.003 / $0.15 / $0.60 |
| **`deepseek-v4-pro`** | DeepSeek-V4-Pro-0813 | 1.6T MoE / 49B 激活 | 1M / 384K | ❌ | 500 | $0.022 / $0.66 / $1.98 |

**高峰价 = 低峰价 × 2。** 但别被「高峰」吓住：官方定义的高峰只有 **UTC 01:00–04:00 与 06:00–10:00、周一至周五、不含中国法定节假日**——换成北京时间正好是 **09:00–12:00 和 14:00–18:00 两个工作时段**。也就是说**夜里、清晨和整个周末都是半价**，批处理与评测任务挪到晚上能直接砍一半成本。缓存命中约为未命中的 1/50（Flash）和 1/30（Pro），把长 system prompt 和文档固定在请求最前面即可命中。

#### 接口层：三种协议，加一个 Beta 通道

| 格式 | Base URL | 用途 |
| --- | --- | --- |
| OpenAI Chat Completions | `https://api.deepseek.com` | 事实上的默认入口，改个 `base_url` 就能把现有 OpenAI SDK / 工具切过来 |
| OpenAI Responses | 同上 | 新版 agent 接口，Codex 一类工具走这条 |
| Anthropic Messages | `https://api.deepseek.com/anthropic` | 给 Claude Code 及兼容 Anthropic 的客户端直连（走 `x-api-key` 认证） |
| Beta | `https://api.deepseek.com/beta` | FIM 补全、对话前缀续写、严格工具模式 |

两档模型的能力基本对齐：JSON 输出、工具调用、Responses API、Anthropic API、对话前缀续写（Beta）、FIM 补全（Beta，**仅非思考模式**）。**唯一的硬差异是图像输入只有 Flash 支持**，Pro 是纯文本模型——要「看图改代码」就得走 Flash。

#### 思考模式是开关，不是另一个模型

`deepseek-chat` / `deepseek-reasoner` 两个旧名字已于 **2026-07-24 退役**，R1 式的显式推理变成 V4 的**思考模式**：请求里传 `thinking: {"type": "enabled"}`（**默认就是开启**），`reasoning_effort` 取 `low` / `high`（默认）/ `max`。三个容易踩的点：

- 思考模式下 **`temperature` 无效**，`tool_choice: "required"` 会直接返回 400——这类请求要先把思考关掉
- 默认 `max_tokens` 随档位变：关闭思考 8K、开启 64K、`max` 档 128K
- 带工具的循环里，上一轮的 `reasoning_content` 必须**原样回传**，否则 400；不用工具时可以省略

#### 周边 API：搜索、抓取、解析、语音

| 能力 | 接口 | 价格 | 备注 |
| --- | --- | --- | --- |
| 联网搜索 | `POST /v1/tools/search` | $0.75 / 千次成功请求 | 支持 `site:`、`lang:`、`after:`、`before:`、精确短语等检索符；返回带 `rerank_score` 与权威度分级（0–4） |
| 网页抓取 | `POST /v1/tools/fetch` | $0.75 / 千次成功请求 | 直接返回 Markdown 正文 |
| Web Tools | 随对话由模型自行调用 | 同上 | 在 DSH、Claude Code、Codex 里触发的搜索同样计费 |
| 文件解析 / OCR | 文档解析、OCR API | $0.225 / 千页 | 扫描件先过这一层，再喂给模型 |
| 语音合成 TTS | TTS API | 限时五折 $0.225 / 万字符（原价 $0.45） | |
| 语音识别 ASR | ASR API | 限时五折 $0.058 / 小时（原价 $0.116） | |

几个计费与配额细节：搜索/抓取**只对成功请求计费**，失败、空结果、超时都不算钱；两者 QPS 上限分别是 100 与 25，**按账号统计而非按 Key**，和模型并发上限互不占用。此外还有 `GET /models`、`GET /user/balance` 与 Files 等管理接口。

#### 三个名字上的坑

- ⚠️ **`deepseek-v4-flash`、`deepseek-v4-flash-vision-exp` 仍可用，但对应模型已退役**——请求会被路由到 V4.1-Flash 并按 Flash 价计费（2026-09-10 起）。老代码不改也不会报错，但你以为在调旧模型，其实已经换人了。
- ⚠️ **不存在「DeepSeek V4.1-Pro」**。09-10 的发布说明里曾写要把 `deepseek-v4-pro` 的请求临时路由到 Flash「直到 V4.1-Pro 发布」，开发者反对后官方撤回，这个名字至今**没有模型卡、没有价格行、没有权重**。中文文章里给它编的参数与价格，都是把家族数据挪了个标签。
- ⚠️ 官方文档在 `api-docs.deepseek.com`，控制台在 `platform.deepseek.com`；`deepseek.ai` 一类站点是第三方整理页，数字大体对得上但**不能当官方口径引用**。

> 想自己搭 agent 的话，DeepSeek 官方还开了一个 MIT 协议的运行时 **DSH（DeepSeek Harness）**，`Model + Harness = Agent` 这个说法就是从它来的——详见[第四章 CLI 工具](../chapter04/04-cli-tools.md)。

## 怎么读 2026 年的版本号

2026 下半年起，厂商集体放弃了「一个模型一个版本号」的线性叙事，改成**同代多档 + 推理档位**。直接后果是：**版本号大不等于能力强**。读规格表时先分清四层：

| 层级 | 例子 | 怎么看 |
|------|------|--------|
| **代际** | GPT-6 → GPT-6.1、Gemini 3.8 → Gemini 4 | 只代表训练批次，常伴随架构与知识截止变化 |
| **同代档位** | Astra / Sol / Terra / Luna；Argon / Carbon；Opus / Sonnet / Haiku；Luna 型低价档 | **这是同一代的不同裁剪**，Terra 弱于 Sol 不代表「版本更低」 |
| **推理强度** | `low / medium / high / xhigh`、Gemini 的 thinking level、Kimi 的 Highspeed | 同一模型换个档位，分数与成本可以差一倍以上 |
| **渠道与别名** | Bedrock / Vertex / 第三方路由的 ID；`-preview`、`-flash`、`-lite` | 同名不同渠道的限制与价格可能不同，`preview` 还有下线日 |

四条实用规则：

1. **比价前先对齐档位**。「$1/$5」通常是该代最便宜的那一档，拿它和别家的旗舰价比是错的。
2. **`preview` 不是产品**。Qwen4-Max 预览只到 2026-11-25，写完的代码要留好换模型的余地。
3. **看到「同代多档」先问一句：它替代的是谁**。厂商常把新档插在旧旗舰下方（如 6.1 Terra 之于 6.1 Sol），不是简单升级。
4. **模型名可能是个滚动别名**。`deepseek-flash` 恒定指向「该档当前版本」（现在是 V4.1-Flash-1017），厂商升级时你不改一行代码就换了模型。要锁定行为，就把具体版本号写进配置和回归测试，别只记别名。

## 延伸：三种不是「LLM」的模型形态

上面两张表列的都是**可调用的 LLM API**。但 2026 年「模型」这个词的外延已经扩大——选型时会遇到三类形态完全不同的东西，它们的评价标准（benchmark、延迟、成本）与 LLM 不通用。

| 形态 | 代表 | 它做什么 | 关键区别 |
|------|------|---------|---------|
| **决策模型** | Jev（TypeSafe AI） | 只输出带概率的类型化判定：分类、评分、真/假 | 不生成文本，结构上无法「胡说」；延迟 70–500ms（2026-09 发布） |
| **世界模型** | Genie 3、NVIDIA Cosmos、Marble、V-JEPA 2 | 理解并预测物理世界的演化，生成可交互环境 | 吃视频级算力；主战场是仿真与具身智能，尚不能直接替换 LLM |
| **专家混合（MoE）** | 多数前沿开源模型 | 稀疏激活——推理时只调用部分「专家」子网络 | 是**架构**而非产品，决定推理成本与吞吐 |

### 决策模型：Jev

由 TypeSafe AI 于 2026-09 发布，创始人是前 OpenAI 研究员 Diogo Almeida（曾参与 ChatGPT 的指令遵循训练）。它属于「System One」路线：**不生成任何文本**，而是接收结构化状态（工单、消息、JSON），返回带校准置信度的答案。三种提问原语：

- **Choice** —— 从至多 255 个预设选项中选一个，附各选项概率
- **Score** —— 按 2–10 级的有序标准打分，结果可落在两级之间
- **Noul** —— 是/否判断，返回 0–1 的概率（名字取自 Bernoulli）

它的定位是「快慢分工」里的快判断层：昂贵的大模型负责规划（慢思考），高频、原子化的判断交给决策模型。价格约 $0.042 / 百万输入 token，输出不计费。

> ⚠️ **两个使用前提**：① 官方与集成方（Pydantic）均提示 **prompt injection 可影响其判定**——不适合单独作为 agent 的安全门禁；② 计数、算术、日期处理不可靠，且英文优先，**目前未向中国大陆开放**。

### 世界模型（World Model）

目标是让模型理解物理世界如何演化，而不只是处理语言。2026 年分成两条技术路线：

- **生成式路线** —— 直接生成像素。Google DeepMind **Genie 3**（11B 参数自回归 Transformer，720p / 24fps）可实时生成可交互环境，2026-01 起经 Project Genie 向美国 AI Ultra 订阅者开放；Waymo 已用它微调出 **Waymo World Model**，专门生成现实中罕见的驾驶场景。NVIDIA **Cosmos** 是开源的世界基础模型平台，主要产出合成训练数据。
- **隐空间路线** —— 只预测表征、不重建像素。Meta **V-JEPA 2** 用约 100 万小时视频预训练，再加仅 62 小时机器人数据，即可零样本完成抓放操作。Yann LeCun 于 2026 年初离开 Meta 创办 **AMI Labs**，专攻这条 JEPA 路线。

目前主要用于自动驾驶仿真、机器人训练与内容生成，**还不是能直接替换 LLM API 的产品**。

### 专家混合（MoE）

MoE 是架构而非产品：模型内部有多个「专家」子网络，每次推理只激活其中一小部分。因此**总参数量**（决定能力上限）与**激活参数量**（决定推理成本）是两个不同的数——看到「总参数 235B / 激活 22B」这类标注就是这种情况。它是当前主流开源模型压低推理成本的通用手段，选型时应关注**激活参数**而非总参数。
